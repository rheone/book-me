# Profiles

One folder per reader, created by book-me's first-run interview:

```
<name>/profile.json   setup and taste (schema: ../reference/profile.md)
<name>/tracker.csv    every pick and decision (../reference/tracker.md)
<name>/history/       exports, offloads, archived profiles (../reference/history.md)
```

These folders hold personal reading data. Keep them out of anything you share or publish; share only `SKILL.md`, `reference/` and `template.json`.
